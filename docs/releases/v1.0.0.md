# HB Continuum v1.0.0

The first stable source release, for personal use. Published without a signed
or notarized installer; the native desktop application is qualified on macOS
Apple Silicon only.

"Stable" describes the archival core and the frozen storage formats of this
series. It does not describe feature completeness. This file mirrors the GitHub
release notes; `claim:` comments tie each claim to
[implementation status](../engineering/IMPLEMENTATION_STATUS.md).

## What this release does

- **Preserves originals.** EML files are stored under SHA-256 with IMAP or file
  provenance; imported originals are never rewritten. MBOX containers can be
  imported with reconstruction provenance recorded separately from original
  EML. <!-- claim: email-preservation -->
- **Keeps a searchable history.** SQLite FTS5 across email, Facebook exports
  and documents, with unified search, timelines and collections.
  <!-- claim: unified-search -->
- **Supports research with citations.** Bounded evidence retrieval, validated
  citations and optional loopback Ollama. Local AI stays disabled until
  enabled. <!-- claim: research-conversations -->
- **Protects the databases.** SQLCipher archives, explicit plaintext-to-encrypted
  migration, encrypted backup and restore, and an in-app statement of what
  encryption does not cover. <!-- claim: encrypted-creation -->
- **Recovers safely.** Verified backups, integrity checks, orphan recovery and
  index repair. <!-- claim: backup-restore -->
- **Stays local.** No telemetry, advertising, subscription or mandatory cloud
  account; GPL-3.0-only.

## Verification

- 388 Python tests pass on Python 3.12 (24 skipped without `sqlcipher3`).
- CI runs the suite on Linux, macOS and Windows, plus a dedicated encryption job
  that installs SQLCipher and runs the security vector script on two platforms.
- `mypy` is clean over the configured file set, with and without `sqlcipher3`.
- Documentation claims are checked against the implementation inventory in CI.

## Known limits

- Encryption covers the three SQLite databases only. Raw EML under `raw/`,
  external documents at their original paths, preferences, exports, reports and
  logs remain plaintext. Use full-disk encryption as well.
- The desktop application is qualified on macOS Apple Silicon; Linux and Windows
  packaged builds are neither built nor claimed.
- MBOX export, incremental IMAP synchronization and richer research tooling are
  not in this release.
- Research retrieval is keyword/FTS5, not semantic. Model output is not
  evidence.
- The `glib` advisory affecting Tauri's Linux-only GTK dependency is deferred to
  a deliberate framework upgrade.
- No independent security audit has been performed.

Do not use HB Continuum as the sole copy of irreplaceable evidence. Keep
independent backups and test restoration.

## Upgrading

Archives from v0.3 through v0.5 open through the normal transactional
migrations. Back up and verify before upgrading. Migration to an encrypted
archive is explicit and never deletes the source.
