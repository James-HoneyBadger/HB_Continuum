# HB Continuum v0.5.0-beta

A source release of the local-first archive and historical research workstation.
This is a beta release; it is not a claim of commercial certification, signed
distribution or universal platform support.

Published 2026-11-28. The `v0.5.0-beta` tag points at the current `main` head.
This file mirrors the GitHub release notes; HTML-comment `claim:` markers tie
each claim to a row in
[implementation status](../engineering/IMPLEMENTATION_STATUS.md), and
`scripts/check_doc_fidelity.py` fails the build if a claim is not recorded as
Implemented or Experimental.

## Highlights

- **Practical historical research:** bounded evidence retrieval, all-term
  matching with a broader fallback only when needed, follow-up conversations,
  validated citations, missing/contradictory evidence reporting, readable source
  navigation and a synthetic multi-year demonstration. <!-- claim: research-conversations -->
- **Document and attachment research:** local text, Markdown, CSV, JSON, PDF and
  DOCX ingestion where optional extractors are installed; attachment text
  indexing and merged document/email timelines. <!-- claim: document-ingestion -->
- **Encrypted archives:** SQLCipher-backed new archives, explicit
  plaintext-to-encrypted migration, in-memory unlock/lock, encrypted database
  backups and a documented threat model. Existing plaintext archives remain
  usable and are never migrated automatically. <!-- claim: encrypted-creation -->
- **Safer archive operations:** verified backup/restore, encrypted snapshot
  handling, scheduled-sync deferral while locked, migration validation and
  explicit recovery limitations. <!-- claim: backup-restore -->
- **Everyday desktop usability:** explicit first-run archive discovery and
  creation, native macOS folder chooser and menus, restored-archive reopening,
  recursive `.eml` folder import, clearer import progress, reader navigation and
  improved error handling. <!-- claim: first-run-archive -->
- **Unified search:** keyword search across archived email, catalog records and
  documents with source labels and paginated results. <!-- claim: unified-search -->

## Verification

The automated suite covers the modules named in the status inventory; CI runs it
on Linux, macOS and Windows for Python 3.12 and 3.13, plus static analysis,
frontend build and engine packaging checks.

The automated suite and synthetic workflows do not inspect or modify the
owner's personal archive.

## Important limits

- **Beta status.** No stable version number or signed/notarized installer is
  included.
- **Desktop qualification is macOS Apple Silicon only.** Linux and Windows
  source paths are exercised by CI, but packaged desktop applications for those
  platforms are not qualified.
- Creating an encrypted archive needs the optional `sqlcipher3` package and is
  currently a command-line operation (`dispatch.py init-encrypted`); the
  desktop's own archive creation produces a plaintext archive that must be
  migrated explicitly.
- Raw EML files, external documents, configuration and exports remain outside
  the database encryption boundary.
- Research retrieval is keyword/FTS5, not semantic. Model output is not
  evidence.
- Do not use HB Continuum as the sole copy of irreplaceable evidence.

## Upgrading

Existing v0.4/v0.3 plaintext archives open through the normal transactional
migrations. Back up and verify an archive before upgrading. Encryption is
opt-in: create a new encrypted archive or migrate to a separate encrypted
destination; the original is not deleted automatically.
